# 거상스쿨 블로그

이 저장소는 Next.js가 아닌 정적 HTML/Vercel rewrites 구조입니다. `node blog/build.js`를 실행하면 `blog.html`, 6개의 `blog-*.html`, 공통 메뉴, `vercel.json` 라우트와 `sitemap.xml`을 생성·갱신합니다. 같은 명령을 반복해도 글이나 메뉴가 중복되지 않습니다.

## 콘텐츠 원본

`blog/posts/*.js`의 6개 객체가 제목, 요약, 발행일, 본문, FAQ, 출처, CTA의 단일 원본입니다. 현재 공개 대상으로 준비한 글은 릴스 3편과 스레드 3편뿐입니다. 게시 날짜는 실제 배포일인 2026-09-17로 기록했습니다. 후속 글은 원본 파일과 이미지 5장을 준비한 뒤 빌드 목록에 추가해야 합니다.

## 이미지

각 글의 `images/blog/<slug>/`에 `cover.png` 1장과 `body-1.png`부터 `body-4.png`까지 4장이 있습니다. 총 30장 모두 서로 다른 이미지이며 1672×941 PNG입니다. 이미지 생성 도구의 built-in 모드로 제작한 설명용 사진이고, 실제 수강생이나 실제 고객의 장면이 아닙니다. 모든 상세 페이지에 이를 명시합니다.

공통 프롬프트 기준: 한국의 소상공인 카페·작업실에서 스마트폰으로 릴스를 제작하거나 스레드 글을 기획하는 현실적인 장면, 자연광과 실제 질감, 가로형 사진, 얼굴 식별 없음, 읽을 수 있는 글자·로고·워터마크 없음. 각 파일은 글의 섹션에 맞춰 촬영 준비, 대본, 초안 작성, 점검 등의 서로 다른 장면으로 생성했습니다.

## 배포 전 확인

1. `node blog/build.js`
2. `git diff --check`
3. `/blog`에서 릴스 3편·스레드 3편, 필터, 카드 링크 확인
4. 각 글에서 표지 1장·본문 이미지 4장, 제목·canonical·구조화 데이터 확인
5. GitHub `main` 반영 후 Vercel 공개 URL에서 다시 확인

블로그가 실제로 공개되기 전에는 외부 콘텐츠 관리 데이터베이스의 발행 상태를 변경하지 않습니다.
